# 音楽（BGM）— 音楽係

合計 約4.8MB。形式は AAC-LC（.m4a）・ステレオ・96kbps・48kHz。

### 測った数字（最終の m4a）
- 聴感の音量：5曲とも -20 LUFS（ffmpeg ebur128）。true peak は -6.9〜-10.2 dBFS。
- 3kHz 以上の量：全体より 21〜38dB 小さい（耳に刺さる高音なし）。
- 0.4秒ごとの音量：となりとの差は最大 7.3dB（メロディの休みのあとに戻るところ）。0.05秒の最大は平均 +3〜4dB 程度で、急な大きな音なし。いちばん静かな 0.4秒でも -30dBFS 程度で、無音の隙間なし。
- 書き出しは seed 固定なので毎回ほぼ同じ音になる（Chrome の計算の細かい差で WAV がビット単位まで一致はしない。数字は同じ）。
- つなぎ目：書き出した WAV は 1周目と 2周目の差が -72dB 以下（完全に周期的）。AAC にした後のつなぎ目の段差は、ふだんの1サンプルの段差（中央値）と同じくらい。

## 作り方（オフライン書き出し）
1. 作曲データ `assets/bgm/src/songs.js`：コード（`chart('Fmaj7 | Am7 D7 | ...')`、1小節に2つなら半分ずつ）とメロディ（`'A4:1 C5:.5 r:.5 ...'` ＝ 音名オクターブ:拍数、r は休み）を書く。伴奏（ピアノの刻み・ボサノバのギター・ベース・打楽器）はその下の JS で並べる。
2. 音のエンジン `assets/bgm/src/engine.js`：ヘッドレス Chrome の OfflineAudioContext で鳴らす。
   - 音色は JS で1音ずつ波形を作る：ピアノ（14倍音×2本の弦、少し非整数）、マリンバ（1・3.93・9.2倍）、ビブラフォン（1・4・10倍＋モーターの揺れ）、オルゴール（1・2・5.97倍＋わずかなうなり）、ガラスのベル、エレピ（FM）、ナイロンギターとウッドベース（Karplus-Strong）。パッド・ドラム・泡は Web Audio のノード。
   - 強く弾くほど明るく（ローパスが開く）。和音は下から少しずつずらして弾く。タイミングと強さを seed 固定で少し揺らす（毎回同じ音になる）。
   - 残響は乱数で作ったインパルス応答（seed 固定）＋ConvolverNode。
   - ループ：曲を 3 周ぶん予定に入れて 2 周目だけを取り出す（前の周の残響・余韻が頭に乗った「ずっと回っている状態」になる）。LFO の速さもループの長さで割り切れる値にする。ループの長さは 0.01 秒の倍数（44.1k/48k どちらでも整数サンプル）になるテンポ・小節数にする。
   - ファイルは「ループ L 秒＋先頭 2 秒のくりかえし」。再生側は loopStart=1.0 から L 秒を回すので、AAC の先頭の無音（エンコーダの遅れ）があっても周期の区間の中で切れる。
3. 書き出し台本 `assets/bgm/src/render.mjs`：Chrome で書き出し → 16bit WAV → ffmpeg で LUFS を測って -20 LUFS（true peak は -3 dBFS まで）にそろえ AAC 96kbps に → もう一度デコードして音量・無音・つなぎ目を測る。

```
node assets/bgm/src/render.mjs                 # 5曲ぜんぶ（1曲 3〜6分。一時フォルダ/osakana-bgm に出る）
node assets/bgm/src/render.mjs suichu --install  # 1曲だけ作って assets/bgm/ に入れる
```
ひつようなもの：Node、ffmpeg（PATH）、Chrome（`CHROME_PATH` で変更可）、playwright-core（`PLAYWRIGHT_CORE` にパス。無ければ Claude の作業フォルダの `*/pw/node_modules` をさがす）。リポジトリに npm の依存は入れない。

### 曲を足すとき
1. `songs.js` に `BGM.SONGS.<id> = () => { ... }` を足す（いまの曲をまねる）。L（小節数×拍子×60/BPM）が 0.01 秒の倍数になるようにする。
2. `node assets/bgm/src/render.mjs <id> --install`。出力の `badEvents:0`・`maxJumpDb`（8 以下がめやす）・`winMinDb`（-40 より上）・メロディの拍数ログ（区切りが小節にそろっているか）を見る。
3. `js/bgm.js` の `TRACKS` に `{ id, name, file, mood, loop: L }` を足す。
4. `demo/bgm.html` で聞いて、つなぎ目を確認。
5. 部屋・ゲーム係に、`sw.js` の FILES に `assets/bgm/<id>.m4a` を足してもらう（オフライン用）。

## 再生の部品 js/bgm.js（部屋・ゲーム係むけ）
```js
import { TRACKS, initBgm, play, stop, setVolume, current, onBgmChange } from './bgm.js';
initBgm();            // 起動時に1回。前回オンなら、つぎのタップで自動で流れる
play('hidamari');     // 曲を選んだとき（タップの中で呼ぶ）。オンになる
stop();               // オフ（0.8秒でフェードアウト）
setVolume(0.6);       // 0〜1（既定 0.5。実際の音量は 2乗）
current();            // { id, on, playing, volume }
onBgmChange(fn);      // 状態が変わったら fn(current())（なくてもよい）
```
- 曲の切り替えは 1 秒のクロスフェード、開始は 1.5 秒のフェードイン。
- 連打しても最後に選んだ曲だけ鳴る（世代カウンタ）。デコード済みは今の曲（切り替え中は前の曲も）だけ持つ。1曲ぶん 約35MB のメモリ。
- 保存：localStorage `osakana-room-bgm` に `{ on, id, volume }`。
- 確認ページ：`demo/bgm.html`。

### iOS / iPadOS の注意
- 音はユーザーの操作のあとでしか出せない。`play()` はボタンのタップの中で呼ぶ。起動直後はタップを待つ（initBgm がタップを見張る）。
- マナーモード（消音スイッチ）では Web Audio は鳴らないことが多い。子ども向けなので、わざとそのまま（`navigator.audioSession` は触らない）。「鳴らない」と言われたらまず消音スイッチを確認。
- アプリが裏に回ったら止め（フェード→suspend）、戻ったら再開。電話・Siri・画面ロックなどで止められた（interrupted）ときは、つぎのタップで再開する。Safari は再開できないことがあるので、実機（Safari とホーム画面から起動の両方）で確認すること。
- `sw.js` の FILES に `assets/bgm/*.m4a` 5つを足さないと、オフラインで BGM が鳴らない（部屋・ゲーム係の持ち場）。

## 相談の記録（Codex と agy）
### 相談1：作り方（2026-11-07）
- 両者一致：リアルタイム合成ではなくオフライン書き出し。AAC-LC の .m4a・ステレオ・96kbps（80kbps はシュワシュワが出やすい）。マナーモードは尊重してよい。
- agy：48kHz にそろえる（iPhone/iPad の標準）→ 採用。低音を中央に、左右は 30〜50% の穏やかな広がり。サイン波だけのベースは小さいスピーカーで消える → 倍音のあるベース（Karplus-Strong＋サイン）に。曲名「ローファイ」は子どもに伝わらない → 「ゆらゆら ティータイム」。水中曲はリディアだけだと不思議すぎる → 基本はメジャーで #11 は要所だけ。オルゴールは 3/4・90BPM で 40小節は半端 → 48小節（96秒）。
- Codex：`start(0, loopStart)` で始める、`statechange` も見張る、表示中かつオンのときだけ再開、RMS ではなく LUFS でそろえる（-20 LUFS 出発）、リリースや LFO も周期化 → 全部採用。
- agy：フェード前に `setValueAtTime(現在値)` でいかりを打つ、連打は世代カウンタ、古い音は stop＋disconnect → 採用。
### 相談2：作曲データの点検（2026-11-07）
- 両者一致：ぽかぽかの B のオルゴール重ねが1オクターブ上で高すぎ → 同じ高さに。ひだまりの後半は打楽器が多い → B ではリムを休み、最後の A ではシェイカーを休む（同時に鳴らさない）。
- agy の「ぶつかる音」指摘 → 採用：ぽかぽかの Fmaj7（メロディの F と E がぶつかる）を F6 に、8小節目・12小節目のメロディ。ひだまり 6小節目を B7b13 に、1小節にコードが2つの小節はギターを 1・3・4拍目に。ゆらゆらのベースの半音つなぎ（和音とぶつかる）を 5度に、1まわり目のドラムを軽く、空っぽだった 1まわり目にエレピの合いの手。オルゴールの伴奏をメロディより下に。すいちゅうはメロディのある所でベルを控えめ・高さを E5 まで。
- Codex の指摘 → 採用：すいちゅう 20小節目の E5（G#m7 と半音）をやめる・2まわり目のベルを 4分音符に、ゆらゆらのキックを弱く・12/20小節目の頭を F5 に、オルゴールの C6 の山を A5 に。
- 似ている曲：agy は ぽかぽかの出だし（分散和音で上がる形）と ひだまりの出だし（同じ形を1音上でくり返す）を「定番フレーズに近い」と指摘。Codex は「特定の曲との一致は見当たらない、進行の共通は定型の範囲」。念のため ひだまりの 3〜4小節目を作り直した（1音上のくり返しをやめた）。コード進行（ii–V–I など）は誰でも使う型なので残した。
- ゆらゆらの 4拍目で音がやせて次の1拍目で 12dB 跳ねていた（測定で発見）→ エレピを長めに伸ばし、キックを弱めて 6dB 以下に。
