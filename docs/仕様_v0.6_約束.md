# v0.6 係どうしの約束（まとめ役）

## ユーザーの要望（まとめ）
1. 「かりすいそう」→「おやすみすいそう」に名前をかえる。
2. すいそうも「そうこ」に しまえる（へやは 6つまで。これから こだいの うみ・たんぼ・ぬまち などの すいそうも ふえるので、うみを 6つ そろえたい人もいる）。
3. チュートリアルの さいごに「わからない ことが あったら ヘルプを みてね」。
4. ぼうけん：これまでに あつめた ハート（heartsTotal）が 300 で ひらく。へやの 左下に はじめから ロックつきで 見せて「ハートを 300 あつめよう」。うみ（つり）と いけ（ガサガサ）。
5. 個体差：おとなに なったときの おおきさに ばらつき（ふつう分布）。よく たべる・ビタミン・えいようの ある えさ・バランスよく → おおきく なりやすい。えさの しゅるいを ふやす。カードで「その しゅるいの 中で どのくらいか」、ずかんに いちばん ちいさい／おおきい きろく、上位10% の おおきさが 手に入った しゅるいに おうかん。手に入れたとき 1% で キラキラ。
6. ミッション：いつも 5つ 見える。かずを 大はばに ふやす。

## データの 形（変えない）
### 水の しゅるい
- `t.water` は `'fresh' | 'salt' | 'pond'`（これから ふえる）。**`water === 'salt' ? … : 'fresh'` の ような 2つだけの 書きかたは やめて**、balance.js の `WATERS`（ぼうけん係が 作る）を 見る：
  `export const WATERS = { fresh: { name: 'かわ', items: ['fresh','both'] }, salt: { name: 'うみ', items: ['salt','both'] }, pond: { name: 'いけ', items: ['fresh','both'] } }`
  （items＝その すいそうに 入れられる 飾り・器具の water）
- state.js の migrate で 'pond' が 'fresh' に かわらない ように する（ぼうけん係）。

### 生きもの（fish.js・図鑑係）
- いけの 生きもの：`water: 'pond'`、`obtain: 'gasagasa'`、`price: null`（おみせに 出ない）。20しゅるい くらい。
- うみの つりの 生きもの：`water: 'salt'`、`obtain: 'fishing'`、`price: null`。ペットショップに いない ふつうの 海づりの 生きもの 中心（しんかいは 入れない）。タコ・イカは レア。
- `rarity` 1〜5。出やすさは ぼうけん係が balance.js の ADVENTURE で rarity から きめる。
- おみせの 生きもの は `obtain` なし（＝'shop'）。

### 手に入れかた（だれでも 使う）
- 生きものは かならず `sim.createFish(state, speciesId, { source, rnd })` で つくり、`sim.addDex(state, f)` で ずかんに のせる（まとめ役が 用意ずみ）。個体差係が この 2つの 中に おおきさ・キラキラ・ずかんの きろくを 足す。ほかの 係は 中身を きにしなくて よい。
- すいそうに 入れる 場所が ないときは おやすみすいそう（state.box）へ（ゲーム係の toBox の しくみ）。

### 個体差（個体差係）
- 魚に 足す 項目は 個体差係が きめる（例：f.sizeZ・f.shiny）。ほかの 係は `sim.sizeOf(f)` → `{ cm, maxCm, pct, crown }`（pct は その しゅるいの 中での 位置 0〜100）と `f.shiny` だけを 使う。
- ずかん：`state.dex[id]` に `minCm`・`maxCm`・`crown`（true/false）・`shiny`（かず）を 足す。

### すいそう と そうこ（ゲーム係）
- へやに おける すいそうは 6つ（いまと おなじ）。`state.storage`（すいそうの 配列）に しまえる。しまった すいそうは 時間が とまる。
- `sim.addTank(state, water, includes)` は へやが いっぱいなら そうこに 入れる（もどりちに `stored: true`）。ぼうけん係の「いけの すいそう プレゼント」も これを 使う。
- すいそうの かずの 上限（へや＋そうこ）は ゲーム係が きめる。

### ミッション用の かぞえ（state.stats・inc(state, key)）
- ぼうけん係：`fishing`（つった かず）、`gasagasa`（ガサガサした かず）、`adventureOpen`（ぼうけんが ひらいたら 1）
- 個体差係：`shinyGet`（キラキラを 手に入れた かず）、`crownGet`（おうかんの しゅるいの かず）、`feedKinds`（あげた ことの ある えさの しゅるいの かず）
- ゲーム係は この 名前で ミッションを 作ってよい（まだ ふえて いなくても 0 として あつかう）。
