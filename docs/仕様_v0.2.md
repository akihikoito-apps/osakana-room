# 仕様 v0.2（企画・図鑑係）— v0.1 からの差分

v0.1 の仕様（docs/仕様_v0.1.md）はそのまま生きている。ここには **変わること・増えること** だけを書く。数値の本体は `js/data/balance.js` の末尾「v0.2 で 足したもの」と `items.js`・`fish.js`。食い違ったらデータが正しい。

画面に出す文字はひらがな・カタカナだけ（点検ずみ）。魚は死なない／通信しない／閉じている間は時間が止まる、は変わらない。データは node で import できることを確認ずみ。

## 0. 本人の要望と、この文書の対応

| 要望 | 章 |
|---|---|
| お店の魚タブを「さかな」「エビ」「かい」の見出しに分ける | 1 |
| 1つめの水槽に6匹で「うみの すいそう」解放・大きな字でお知らせ・海水魚と追加の淡水魚・新しい淡水の水槽・部屋に最大6つ | 2〜5 |
| そうじで あみで水をすくうアニメ | 7 |
| 魚をタップして出るハートを数えて画面に出す | 6 |

## 1. お店の見出し

- 魚タブの中を `SHOP_TABS` の順（さかな → エビ → かい）の見出しで分ける。分け方は `fish.kind`（'fish' / 'shrimp' / 'snail'）。
- 並べるのは **いま選んでいる水槽と同じ水**（`fish.water === tank.water`）の生きものだけ。見出しの中は 買えるものを先に、値段の安い順。
- 解放前（`unlock: 'tank6'` で まだ）の生きものは **かぎつきカード**（絵は影、名前は「？？？」）。カードには `SHOP_LINES.locked`（「1つめの すいそうに 6ぴき いると あえるよ（エビも かいも かぞえるよ）」）と、いまの数「4／6」。かぎつきカードは見出しごとに たたんでおける形がよい。
- 「かい」の見出しが はじめから空にならないように、イシマキガイ（40）は はじめから並ぶ。
- お店の上に「いま えらんでいる すいそう」（`WATER_LABELS`：**かわの すいそう**／うみの すいそう）を出し、水槽を切りかえられるようにする。色だけに頼らず、かわ・なみ の小さな絵をそえる。
- 魚の札には、いまの水槽の魚との相性マーク（◎○×）を v0.1 どおり出す。とくに ルリスズメダイ（いちばん安い海水魚・どうしは ×）は2匹目を選んだときの たしかめ（`SHOP_NIGATE_CONFIRM`）を忘れない。

## 2. 解放（UNLOCK.tank6）

- 条件：**1つめの水槽（state.tanks[0]）の生きものの数が 6 以上**、**または その水槽が いっぱい**（space の合計 ≥ `TANK.capacity`）。
  - 数は 1匹＝1（エビ・かいも1）。space ではない。
  - 「いっぱい」でも解放するのは、キンギョ・エンゼル（space 2）で うまって 6匹に届かない「つみ」を防ぐため（魚を手放せないので）。本人の「6匹」は ふつうの道すじとして残している。
- 判定のタイミング：魚を買った直後と、セーブを読み込んだ直後。
- たっせいしたら `state.unlocks.tank6 = その日`（**永久**。あとで数が減っても戻さない）。
- お知らせ：画面いっぱいの大きな字で `UNLOCK.tank6.banner` を1まいずつ（タップで次へ）。キラキラ。**お知らせの間は時計を止める**。
  1. 「うみの すいそうが かえるように なったよ！ おみせで 1000コイン だよ。」（本人の言葉に合わせて まとめ役が決定）
  2. 「あたらしい さかなや かい、かわの すいそうも おみせに ふえたよ！」
  - 企画係は「かえる」が 買える／飼える で迷うと心配したが、本人の言葉を優先。値段は出す。
- 解放されるもの：`unlock: 'tank6'` の生きもの（淡水6種＋海水8種）と品物（tank_fresh、tank_salt、liverock、coral）。
- 解放前は、ヒント h_unlock_near（1つめの水槽が 4〜5匹のとき）「あと {n}ひきで あたらしい なかまに あえるよ。エビや かいも かぞえるよ。」（{n} = 6 − いまの数）。

## 3. 水槽（TANKS）

| 品物 | id | 値段 | 中身 |
|---|---|---|---|
| かわの すいそう | tank_fresh | 800 | 淡水。ヒーター・ブクブクつき（`includes`） |
| うみの すいそう | tank_salt | 1000（本人の指定。まとめ役が firstPrice 500 を取り消し） | 海水。ヒーター・ブクブクつき |

- うみの すいそう は いつも 1000（本人の指定）。かわの すいそう は 800。
- 部屋に置ける水槽は **6つまで**（はじめの1つを含む）。6つになったら灰色で `SHOP_LINES.tankMax`。
- 買ったら state.tanks に足す：`{ id: 't2'…'t6', water, temp: 25, clean: 100, air: 70, leftover: 0, decor: ['heater', 'air_pump'], fish: [] }`（`TANKS.newTank`、ヒーターつきなので はじめから 25℃）。ふきだし `SHOP_LINES.newTank`。
- 1つの水槽の中身の上限は v0.1 と同じ `TANK.capacity`（space 6）。
- **すべての水槽の時間が同時に進む**（見ていない水槽も tick する）。ヒントは いま見ている水槽について出す。見ていない水槽に げんきが ない魚がいたら、部屋の画面のその水槽に小さな しずくマーク。
- 器具・飾りは水槽ごと（`max` も水槽ごと）。道具（えさ・みずかえセット）は1こ持てば どの水槽でも使える。そうじ・みずかえ の効果は、押したときの水槽だけ。
- コイン（`MULTI_TANK`）：
  - お世話のコインの回数上限（えさ4回・みずかえ3回）は **水槽ごと**。生きものが いない水槽の お世話は コインなし。
  - 1日の お世話コインの合計上限：`50 + 25 × (生きものがいる水槽の数 − 1)`（1つ 50、2つ 75、3つ 100、6つ 175）。
  - ありがとう：水槽ごと1日4回、最低2時間あける（水槽ごと）。全部で1日 `4 + 3 × (生きものがいる水槽の数 − 1)` 回まで（6つで 19）。
- 目安：解放のあと（m_tank6 の 150 を受け取って）、収入 60〜70/日 で うみの すいそう（1000）まで 約2時間（現実）。

## 4. 海水

- 海水の生きものは うみの すいそう にだけ入る。淡水の生きもの・水草（plant）・りゅうぼく（driftwood）は うみの すいそう に入らない（`water`）。いし・ブクブク・ヒーター・フィルター・ライト・おおきな いわ（80、v0.2 から売る）は どちらにも入る。
- 違う水の水槽を選んでいるときは、お店で そもそも並べない（1章）。ずかんから「おみせで みる」などで違う水だったら：
  - うみの すいそう を持っている → `SHOP_LINES.wrongWater`（「{name}は うみで くらすよ。うみの すいそうを えらんでね。」）
  - まだ持っていない → `SHOP_LINES.noSaltTank`（「{name}は うみで くらすよ。おみせで うみの すいそうが かえるよ。」）
  - 淡水の生きもの → `wrongWaterFresh`
- 海水の品物：

| id | なまえ | 値段 | 効果（1こ・/時間） |
|---|---|---|---|
| liverock | ライブロック | 150（2こまで） | きれいさ +0.3。すきな魚の ごきげん |
| coral | サンゴ | 120（2こまで） | くうき +0.3、きれいさ +0.1（どちらも ライトで1.5倍）。すきな魚の ごきげん |

- 計算式（v0.1 の 3-2・3-4・3-3 に足す）：
```
きれいさ += 0.3×n(liverock) + 0.1×n(coral)×L + SNAIL.cleanPerHour×(かいの数 + オトシンクルスの数)
くうき   += 0.3×n(coral)×L
たべのこし −= SNAIL.leftoverPerHour×(かいの数)
```
  - オトシンクルスは `SNAIL.algaeEaterIds`（こけを たべる）。スカンクシュリンプは `CLEAN.cleanerIds`（たべのこし を たべる）に足した。
  - ライブロックは「よごれる速さ」には効かない（フィルター＋ライブロック2こでも、4匹なら ときどき水かえが要る＝水かえのコインが消えない）。
- **ニシキテグリ**（レア5・1200）は `needs: ['liverock']`：ライブロックが入っていない水槽では買えない（ボタン灰色、`SHOP_LINES.needs`）。v0.2 ではライブロックを出せないので、入ったあと無くなることは無い。ミッションの必須にはしない（あこがれの長期目標）。
- 海水の魚は cleanMin 50（ルリスズメ 40、ニシキテグリ 60、かい 30）。v0.1 の けんこう・ごきげん の決まりはそのまま。
- ヒント：h_salt_rock（ライブロックが無く きれいさ < 70）、h_air_salt（くうきが すくない とき。水草の かわりに サンゴを すすめる）。

## 6. ハート（HEART）

- 魚をタップ（なでる）したとき、次の全部を満たせば ハート +1：
  1. その魚から、ゲーム内72分（**現実30秒**。なつき の待ち時間と同じ）のあいだ ハートをもらっていない
  2. 今日（6:00から）**全部の水槽あわせて** もらったハートが 20 こ未満
  3. その魚の けんこう ≥ 40
- いま ハートをくれる魚の上には 小さな キラキラハートを浮かべる（`showReadyMark`。むだな連打を防ぐ）。
- もらえたとき：なつきに関係なく `aq.react(uid, 'heart')`、魚の上から画面のすみの ハートカウンターへ「+1」が飛ぶ。
- もらえないとき：v0.1 どおりのリアクション（happy / heart / spin / sleepy）だけ。
  - 20こに なったとき 1回だけ ふきだし `HEART.doneLine`（「きょうの ハートは いっぱい！ また あしたね」）。カウンターは「20／20」。
  - けんこう < 40 の魚を なでたとき `HEART.restLine`（「いまは やすんでいるよ」）。
- カウンターの見せ方：「ハート 123」と「きょう 8／20」。なつき の ハート（0〜5）と混ざらないよう、カウンターの ハートは キラキラの別の色にする（なつき は魚カードの中だけ）。
- 数えるのは **なでて もらったハートだけ**。餌を食べたときに水槽が自動で出すハートは数えない。
- 保存：`state.hearts`（いまの数）、`state.heartsTotal`（つうさん。後の版でハートを使っても減らない。ミッション 'hearts' はこちら）、`state.daily.hearts`（今日の数）、魚ごとに `lastHeartMin`（最後にハートをくれたゲーム時刻）。ゲーム時刻で数えるので、閉じている間は待ち時間も止まる。
- v0.2 ではハートは貯まるだけ（使い道は後の版）。ただし ハートのミッション（m_hearts20・m_hearts100）は コインのごほうびがある（まとめ役の指示どおり。間接的に ハート → コイン になる）。

## 7. そうじのアニメ（SCOOP）

- そうじボタン → あみで水をすくうアニメ **2秒**（実装は他係）。
- たべのこし を 0 にするのは **アニメの終わり**。アニメの間は えさ・みずかえ・そうじ ボタンを押せない（時計・魚・リアクションは ふつうに動く）。効果は押したときの水槽だけ（途中で水槽を切りかえても）。
- たべのこし 0 のときも アニメはできる（v0.1 では灰色だったが、子どもが あみを使ってみたいので解禁）。そのときは コイン・きれいさ・ミッションの数え（scoop は たべのこし ≥ 1 のときだけ）は なし。ボタンの説明は「たべのこしを すくうよ」（水をきれいにする みずかえ と区別）。
- アニメの途中でアプリが裏に回ったら、そこで終わったことにして たべのこし を 0 にする。

## 9. ヒント・ことば（hints.js）

- 足したヒント：h_air_salt、h_salt_rock、h_unlock_near（{n}）、h_tank_empty。判定は いま見ている水槽ごと。
- 足したことば：`SHOP_LINES`（wrongWater / wrongWaterFresh / noSaltTank / needs / locked / tankMax / newTank）。`{item}` は items.js の name。
- お知らせの文は balance.js の `UNLOCK.tank6.banner`、ハートのことばは `HEART.doneLine` / `restLine`、見出しは `SHOP_TABS`、水槽のよびかたは `WATER_LABELS`、カウンターは `HEART_LABEL`。

## 10. v0.1 のセーブからの移行

セーブのキーは `osakana-room-save-v1` のまま。読み込むときに足りない所を補う（state.js の normalize で）。

- `state.unlocks` が無ければ `{}`。`state.hearts` / `state.heartsTotal` が無ければ 0。`state.daily.hearts` が無ければ 0。魚の `lastHeartMin` が無ければ −∞（すぐ もらえる）。
- 水槽は v0.1 から配列（state.tanks）なので形はそのまま。2つめ以降の id は 't2'〜't6'。tank_salt の `firstPrice` を使ったかは `state.stats.firstBuy_tank_salt` などで覚える。
- **読み込んだ直後に解放の判定をする**。v0.1 ですでに1つめの水槽に6匹いる（または いっぱいの）人は、そこで大きな字のお知らせを1回出して解放する（`state.unlocks.tank6` が無いときだけ）。
- ミッション：v0.1 で受け取りずみのものは そのまま。新しい m_snail・m_tank6・m_hearts20・m_salt・m_tank2 は配列の途中に入るので、見えている3つが入れかわることがある（問題なし）。m_tank6 は条件を満たしていれば すぐ達成。
- 品物：liverock・coral・rock が売られるようになった（v0.1 では null）。v0.1 で買えたものの値段は変わらない。
- 魚のデータ：v0.1 の10種の数値は変えていない（プラティなど新しい種類だけ）。
- そうじ：たべのこし 0 でもボタンが押せるようになる（UI の変更）。
- CLEAN.cleanerIds に skunk_shrimp を足した（v0.1 の水槽には いないので影響なし）。

## 11. 実装係への注意

- 解放の判定は「1匹＝1で6以上」または「space がいっぱい」。
- お世話コイン・ありがとう の上限は「水槽ごと」と「全部で」の2段。全部での上限は「生きものがいる水槽の数」で計算する（からの水槽を並べて上限を増やせないように）。
- ハートの待ち時間は魚ごと（ゲーム内72分）、「1日20こ」は全体。lastHeartMin と daily.hearts は保存する。
- かい・オトシンクルス（SNAIL）、ライブロック・サンゴ（cleanPerHour / airPerHour）は v0.1 の式に足すだけ。
- 絵がまだ無いもの（デザイン係へ）：生きもの15種（assets/fish/<id>.png）、アイコン tank_fresh・tank_salt・coral。
