# v0.10 係どうしの約束（まとめ役）

v0.10 は 4つの係が 同時に作業する：3D係（正面の われめ・カエルと カメの およぎ）・つり係（こうきゅう えさ）・**のうりょく係**・**レース係**。ほかの係の持ち場は さわらない。ここに書いた「名前・形」は 変えない（変えたいときは まとめ役に報告）。

## レースの 要望（2026-11-27 本人と 確認ずみ）
- そだてた 魚で レース。プレイヤーが そうさ して、コンピューターの 魚と きょうそう。
- **出られるのは さかな だけ**（エビ・カニ・かい・カメ・カエル は 出ない）。ゆめのすいそうの「さかな」（kind 'fish'。ぬりえ でも オリジナル でも）は 出られる。
- **さんかひ なし・1日の 回数 上限 なし。** 部屋に「レース」ボタン、さいしょ から あそべる。
- 1レース：じぶん 1ぴき ＋ コンピューター 3びき。
- むずかしさ：かんたん／ふつう／むずかしい。かつ（1い）と つぎが ひらく。
- ごほうび：1〜3い で その 魚からの ハート と すこしの しょうきん（コイン）。ハートは 1日20この 上限とは べつ（1いで 5こ が めやす）。回数 上限が ないので、コインは すこしに おさえる（数は レース係が Codex・agy と きめる）。レースに 出ると その 魚の おなかが すこし へる（おなかが すくなすぎる 魚は 出られない か、ちからが でない）。ハートは heartsTotal にも 入る（ぼうけんの 300 に かぞえる）。
- 魚は しなない。まけても かなしく ならない ことば（「つぎは がんばろう」）。

## のうりょく（6つ）
| key | なまえ | きく ところ |
|---|---|---|
| `speed` | はやさ | いちばん はやい ときの はやさ |
| `accel` | かそく | はやく なるまでの みじかさ・ぶつかった あとの たちなおり |
| `stamina` | スタミナ | ダッシュに つかう ゲージの 大きさ・回復 |
| `turn` | まがり | まがりやすさ・こまわり |
| `jump` | ジャンプ | しょうがいぶつを とびこえる 高さ・ちゃくちの はやさ |
| `power` | パワー | ぶつかった ときに おしまけない（マリオカートの おもさ） |

- しゅるいごとの とくい（のうりょく係が 全 さかなに つける。例：マグロ・カツオ系は はやさ、エンゼルは まがり、メダカは かそく、フグは パワー、トビウオは ジャンプ）。
- こたいち：1ぴき ずつ すこし ちがう（手に入れた とき きまる。セーブに のこる）。
- そだつ：ちびっこ → おとな → ビッグ で のうりょくが 上がる。けんこうが 高い ほど・えいようの ある えさを たくさん たべた ほど 上がりやすい（v0.6 の サイズの えいよう・バランスの しくみを さんこうに）。
- レースの 日の けんこうが ひくいと ちからを だしきれない（コンディション）。

### のうりょく係が 用意する（js/race/stats.js、sim.js から `sim.race` として 再輸出）
- `race.canRace(f)` → `{ ok, reason }`（さかな か・おなか 等）
- `race.statsOf(state, f)` → `{ speed, accel, stamina, turn, jump, power }` 各 0〜100（しゅるい＋こたいち＋そだち。コンディション まえ）
- `race.conditionOf(f)` → 0.7〜1.0 くらい（けんこう から）
- `race.effectiveStats(state, f)` → statsOf × コンディション
- `race.cpuStats(level, rnd)` → コンピューターの 魚の `{ speciesId, stats }`（むずかしさ ごとの つよさ。レース係と 相談して 数を きめる）
- 魚の カード（js/ui/tank.js の カード）に のうりょくを 見せる（6かくの レーダー か ぼう グラフ。こども向け）。
- 既存の 魚にも migrate で こたいちを つける（もらいそこね なし）。

### レース係が 作る
- js/race/*（コース・うごき・コンピューターの AI・そうさ）、js/ui/race.js（えらぶ 画面・レース 画面・けっか）、css/race.css、部屋の「レース」ボタン、`sim.race.finish(state, uid, level, rank)` 相当の ごほうび（js/race/reward.js などで。sim から よぶ）。
- そうさ：ひだりに 3D スティック（まがる）、みぎに「ダッシュ」（スタミナを つかって まっすぐ はやく）と「ジャンプ」。指でも マウスでも。
- コース：水の 中の 3D コース。いわ（ジャンプで こえる）・かいそう（おそく なる）・あわの わ（スピード アップ）。カーブ。740×390 の スマホ横でも 1024×768 でも あそべる。
- 魚の 見た目は js/aquarium の fishModel を **import して つかう だけ**（js/aquarium は 3D係が 作業中なので 中身を かえない。かえたい ときは まとめ役へ）。ゆめの さかなの 絵も 出せると よい。
- のうりょくが そのまま うごきに きく こと（statsOf の 数で はやさ・かそく・まがり・ジャンプ・スタミナ・ぶつかり が かわる）。
- ミッション用 stats：`raceRun`（はしった 回数）・`raceWin`（1いの 回数）を inc。
