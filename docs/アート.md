# アート（デザイン係）

絵は Codex（画像生成）が描き、Claude は指示書・取り込み・切り抜き・確認をする。agy は見た目の第三者チェック。
次の版で魚や器具を増やすときは、この文書の「共通指示」をそのまま指示書に貼れば同じタッチで揃う。

## 1. 作画の手順（実際に回した方法）

1. 指示書を Markdown で書く（下の共通指示＋被写体1行）。スクラッチパッドに置き、リポジトリには入れない。
2. `codex exec --skip-git-repo-check -s read-only -C <作業フォルダ> < 指示書.md`
   - 必ずファイルを流し込む（引数で渡すとハングする）。
   - 読み取り専用で動かすので、Codex には保存させない。画像は `~/.codex/generated_images/<セッションID>/exec-*.png` にできる。
     Codex の最後の返事（ログ）にこのパスが出るので、そこから拾ってコピーする。
   - 1枚 50〜220 秒（多くは 1 分前後）。同時に走らせるのは 2 本まで。
   - 生成画像は 1536×1024（横長指定）または 1254×1254（正方形指定）。ときどき最初から透過 PNG で出てくる。
3. 背景抜き：rembg の `birefnet-general` モデル（`~/.rembg/models`、初回に約 1GB をダウンロード）。
   - 元が透過済みなら抜かずにそのまま使う。
   - アルファ 12 未満は 0 にしてゴミを消す → 物の外接矩形で切り出し → 長辺の 3% の余白 → 指定幅に縮小。
   - 300KB を超えたら 256 色に減色（ディザあり）。
   - **細かい葉の水草（カボンバなど）は rembg だと白いもやが残る。** 白背景を「白からどれだけ離れているか＝不透明度」にして色から白を引き戻す方式（色→透明）で抜くときれいになる。
   - 底砂は「元画像」と「縦横半分ずらした画像」を、端の 20% だけ混ぜてシームレスにする（2×2 に並べて継ぎ目を確認）。
4. 市松模様と濃紺の上に重ねた確認画像を作り、目で縁・向き・ひれを確かめる。
5. 一覧画像（灰色の下地に全部並べたもの）を agy と Codex の両方に見せ、意見を比べて直すものを決める。

### 注意（はまったところ）
- Bash で `&` を付けて裏で回すと、止まったように見えても動き続けていることがある。2 本の上限を守るため、裏で回すときは Claude Code の「バックグラウンド実行」を使う。
- Codex のログの画像パスは `C:\Users\...\generated_images\...` の形（バックスラッシュ）。`tr '\\' '/'` でそろえてから拾う。
- ほかの作業の Codex も同じ `generated_images` に書くので、「いちばん新しい画像」で拾わず、必ず自分のログに出たパスで拾う。

## 2. 共通指示（Codex に毎回貼る）

### 魚・エビ（assets/fish/）
- 写実的（リアルな図鑑写真・精密な博物画のような質感）。ただし子ども向けなので、やさしく清潔な印象。口を大きく開ける・歯・傷・病気などは描かない。種として正確に。
- **完全な真横（側面図）**。カメラは体の真横、パースなし。**頭が右、尾が左**。
- 体は水平で、まっすぐ（曲げない）。ひれ（または脚・触角）はすべて見えて、広げた状態。
- 生きものが画像の横幅の約 90% を占め、上下左右に少しだけ余白。体は画像の中央。どこも画面からはみ出さない（長いひれ・触角も画面内に収める）。
- **背景は完全に均一な純白（#FFFFFF）のみ**。影・地面・水・泡・光の筋・反射・グラデーション・文字・枠・透かしは一切なし。
- 照明は均一でやわらかい。輪郭がくっきり分かること。
- 横長の画像（横:縦 = 3:2 くらい。体高の高い魚は 1:1 に近くてよい）。

### 水槽の飾り（assets/room/ の石・水草・流木）
- 写実的（実物の写真のような質感）。やさしく清潔な印象。
- 正面から水平に見た姿（水槽のガラス越しに見る向き）。パースは弱め。
- 物が画像の約 85% を占め、中央に1つだけ。はみ出さない。
- 背景は完全に均一な純白（#FFFFFF）のみ。影・地面・水・泡・反射・文字・枠は一切なし。
- 照明は上からのやわらかい光で均一。

### アイコン（assets/items/）
- 子ども向けゲームのアイコン。やわらかい 3DCG レンダリング風（実物らしい形と質感、角は丸く、明るい色、やさしい印象）。すべて同じタッチ。
- 斜め上から少し見下ろす 3/4 ビューで、物が1つ、中央に大きく（約 80%）。正方形（1:1）。
- 背景は完全に均一な純白のみ。影・床・文字・数字・枠・ロゴは一切なし。電気のコードは短く丸めて画面内に。

### エビ・細いひれの魚に足す一文（チェックで分かったこと）
- 脚は細かく描き込みすぎず体の下に小さくまとめる（虫っぽく見せない）。触角は体長と同じくらいまでに短くし、少し太めにして体の上に沿わせる。
- 糸のように細いひれ（エンゼルの腹びれなど）は、短めで少し幅のあるひれにする（縮小・変形で消えたりちらついたりするため）。

### 石・岩に足す一文
- 小さな穴の集まりは描かない（集合体が苦手な子がいる）。表面はゆるやかなでこぼこと質感だけ。

### アイコンに足す一文
- 電気のコード・プラグは描かない。役割が分かる表現（ヒーター＝ほんのりあたたかい光、ライト＝下向きのやさしい光）を少しだけ。文字は入れない（説明はゲーム画面側で出す）。

### 締めの文（全部共通）
- 画像生成ツールで1枚だけ描いてください。ファイルの保存・コピーはしなくてよいです（こちらで生成画像を回収します）。コードは書かないでください。
- 描き終えたら、生成された画像ファイルのパスを1行で答えて終わってください。
