# 仕様 v0.3（企画・図鑑係）— v0.2 からの差分

v0.1・v0.2 の仕様はそのまま生きている。ここには **変わること・増えること** だけを書く。数値の本体は `js/data/balance.js`（`TANK.fishMax`・`TANK.snailMax`、末尾「v0.3 で 足したもの」の THERMO・CLEAN_FLOOR・VITAMIN）と `items.js`・`fish.js`。食い違ったらデータが正しい。

画面に出す文字はひらがな・カタカナだけ（点検ずみ）。魚は死なない／通信しない／閉じている間は時間が止まる、は変わらない。データは node で import できることを確認ずみ。

## 0. 本人の要望と、この文書の対応

| 要望 | 章 |
|---|---|
| 魚（エビ含む）は6匹のまま、別に 貝を2匹まで | 1 |
| 器具：じどう えさやり・クーラーファン・CO2・プロテインスキマー | 2 |
| ビタミン剤（栄養たっぷり・好き嫌い・歯止め） | 3 |

## 1. 水槽の定員（貝は べつ枠）

- 貝（`kind: 'snail'`）は **space 0**（fish.js で 0.5 → 0 に変えた）。
- 魚・エビは **6匹まで**（`TANK.fishMax`）、かつ space の合計が `TANK.capacity`（6）まで。両方を守る。v0.2 までは space だけだったので エビなら12匹入ったが、本人の「6匹」に合わせた。
- 貝は それとは別に **1つの水槽に `TANK.snailMax`（2）匹まで**。かわ・うみ どちらの水槽も同じ。
- お店：
  - 貝が2匹なら 貝のカードを灰色にして `SHOP_LINES.snailFull`（「かいは 1つの すいそうに 2ひき までだよ。」）。
  - 魚・エビが いっぱいで 貝に あきがあるときは `SHOP_LINES.fishFull`（「さかなと エビは … 6ぴき までだよ。かいなら あと すこし いれられるよ。」）。どちらも いっぱいなら v0.1 の h_full。
- 計算：space を使う式（よごれ `0.4×S`、くうき `−0.5×S`）に貝は入らない（貝は v0.2 の SNAIL の きれいさ・たべのこし の効果だけ）。
- 解放の条件（UNLOCK.tank6）：**今の決まりのまま**。1つめの水槽の生きもの 6匹以上（貝も1匹と数える）、または 魚・エビが いっぱい（6匹 または space 6）。貝2匹だけでは解放しない。（理由は 相談の記録）

## 2. 器具（items.js）

| id | なまえ | 値段 | 水 | max | 効果 |
|---|---|---|---|---|---|
| auto_feeder | じどう えさやり | 200 | どちらも | 1 | ゲームの 8時と18時に、おなか < 50 の魚へ おなか +15。スイッチで いり／きり |
| fan | クーラーファン | 180 | どちらも | 1 | ヒーターと両方あるときだけ：おんど ダイヤル。ファンだけなら何もしない |
| co2_kit | シーオーツー | 250 | かわ だけ | 1 | 水草の くうき だけ 1.5倍、水草が好きな魚の ごきげん +5（水草 0 なら効果なし） |
| skimmer | プロテインスキマー | 250 | うみ だけ | 1 | よごれる速さ ×0.8、たべのこし −0.1、くうき +0.5（/時間） |

- どれも **解放（tank6）のあと** お店に並ぶ（序盤の お店を すっきりさせる）。ビタミンだけは はじめから。
- どれも水槽に入れるもの（`inTank: true`）。id をそのまま `aq.setDecor` に渡す（3D水槽係へ：4つの形が要る。まだ無いときは目立たない小さな箱でよい）。
- co2_kit は うみの すいそう、skimmer は かわの すいそう では灰色（`SHOP_LINES.co2Salt` / `skimmerFresh`）。

### 2-1. じどう えさやり
- ゲーム時計が 8:00 と 18:00 をまたいだとき、その水槽の **おなか < 50** の魚だけ おなか +15（すいている魚の お助け。+15 しても 65 なので、手であげたときの コインの条件 おなか < 80 を じゃましない）。
- **コイン・なつき・そだち（えさボーナス）・ミッション feed・ハート は なし**。たべのこし は作らない。
- 水槽の画面に いり／きり の スイッチ（`tank.feederOn`、はじめは いり）。説明は「おなかが すいた こに すこし あげるよ」。閉じている間は時間が止まるので、るすばん用ではない。
- 落ちる粒の見た目は 3D水槽係と相談（なくてもよい）。

### 2-2. クーラーファン と おんど ダイヤル（THERMO）

| ヒーター | ファン | 向かう温度 | 速さ |
|---|---|---|---|
| なし | なし | へやの温度（20℃） | 0.5℃/時間（v0.1） |
| あり | なし | 25℃ | 1℃/時間（v0.1） |
| なし | あり | へやの温度（ファンは何もしない。`THERMO_LINES.needHeater`） | 0.5℃/時間 |
| あり | あり | **おんど ダイヤル** の温度 | 1℃/時間 |

- おんど ダイヤル：ヒーターとファンが両方ある水槽だけ、水槽の画面に出る。**大きな3つのボタン**：すずしい **23℃**／ふつう **25℃**／あたたかい **27℃**（はじめは ふつう）。水槽ごとに保存（`tank.thermo = 'cool'|'normal'|'warm'`）。「せってい 23ど」と「いま 24ど」を分けて出し、向かっている間は「すずしく しているよ／あたためているよ」。
- **事故を防ぐ（`safeOnly`）：その水槽の生きもの（貝も）の だれかが はんい外になる段は 選べない**（灰色。押したら `THERMO_LINES.outOfRange`「{name}には あわない あたたかさ だよ。」）。読めない子でも ベタを 23℃ にできない。
  - 23℃ は ベタ・エンゼル・ドワーフグラミー・うみの魚の ほとんど（min 24）が はんい外 → その水槽では灰色。27℃ は レッドビー（max 26）が はんい外。
  - ふつう（25℃）は いまの全種の はんい内なので いつでも選べる。全員が はんい内で いちばん ぴったりの段に `THERMO_LINES.recommend`（「みんなに おすすめ」）。
  - あとから入れた魚に いまの段が あわないときは 自動で ふつう に戻して `THERMO_LINES.reset`（`resetOnUnsafe`）。
- **ダイヤルを使う意味（とても ぴったり）**：どの水槽でも、`|すいおん − best| ≤ 1` の魚は ごきげん の目標値 **+5**（v0.1 の「ぴったり +15」に足す。`THERMO.perfectRange / perfectMood`）。25℃ のままでも best 24〜26 の魚は もらえる。キンギョ・レッドビー・ミナミヌマエビ（best 23）は すずしい で、ベタ（27）・エンゼル・ドワーフグラミー（26）は あたたかい で もらえる。
- ヒント h_fan_cold（「おんど ダイヤルを あたたかく してみよう」）は 念のため残す（ふつうは起きない）。

### 2-3. シーオーツー
- 水草の **くうき**（+0.8、1こ・/時間）だけ ×1.5。ライトとかけ算（両方で くうき ×2.25）。**きれいさ は増やさない**。
- 水草が1こ以上あるとき、`likes` に 'plant' がある魚の ごきげん の目標値 +5。
- 水草 0 なら何もしない。ヒント h_co2。

### 2-4. プロテインスキマー
- v0.1 の よごれ の式で、`F`（フィルター 0.5）に さらに ×0.8（両方で 0.4）。
- たべのこし −0.1/時間、くうき +0.5/時間（あわ）。

### 2-5. きれいさ の さいていの よごれ（CLEAN_FLOOR・v0.1 の水槽にも かかる）
- 魚・エビが1匹以上いる水槽では、**きれいさ の1時間の変化は −0.4 より大きくならない**（器具・水草・ライブロック・貝で どれだけ きれいにしても、1時間に 0.4 は よごれる）。みずかえ・そうじ は べつ。
- 理由：フィルター＋スキマー＋ライブロック＋サンゴ＋貝 や、CO2＋ライト＋水草4 で きれいさ が ずっと 100 になり、水かえの出番とコインが消えるため（二人とも指摘）。1日で約 −10、約1日半で 水かえのコインの条件（< 85）になる。

## 3. ビタミン（food_vitamin・VITAMIN）

### 3-1. 買い方・使い方
- お店の えさ の ところに **はじめから** 並ぶ。**100コインで 5回分**。持てるのは5回分まで（残りがあるうちは灰色、`SHOP_LINES.vitaminFull`）。
- 水槽の画面に「ビタミン」ボタン（えさボタンの横）。ボタンに「のこり 3」と、その水槽で食べる魚の数 `VITAMIN_LINES.willEat`（「4ひき よろこぶよ」）。
- **1つの水槽に 1日1回**（ゲームの 6:00 でもどる）。もう あげた水槽では ボタンを灰色にし、押したら `VITAMIN_LINES.doneToday`（「つぎの あさ 6じに また あげられるよ」）。ボタンに「あと ○ぷん」（現実の分）も出す（「あした」だと 現実の明日と まちがえるため）。
- 1回使うと 残りが1減る。0 になったら `VITAMIN_LINES.empty`。
- **その水槽の魚が全員 dislike**（または魚がいない）のときは 落とさない・減らさない・その日の1回も使わない（`allDislike`）。

### 3-2. 食べたとき（魚ごと）
- 落としたら、その水槽の dislike でない魚は全員食べる（`aq.feed` で落として `eat` で決める）。おなか ≥ 90 でも食べる（べつばら）。たべのこし は作らない。
- 効果（`VITAMIN.effect`）：

| すききらい | けんこう | そだち | ごきげん | なつき | おなか | リアクション |
|---|---|---|---|---|---|---|
| love（だいすき） | +15 | +6時間 | +10 | +3 | 0 | jump → 1秒後 heart |
| ok（たべる） | +10 | +4時間 | +5 | +1 | 0 | happy |
| dislike（いつもの ごはんが すき） | — | — | — | — | — | turn（ぷいっ） |

- けんこう は 100 まで（10 の下限は そのまま）。ごきげん の +10 は その場で足すだけ（そのあと目標値へ戻っていく）。
- そだち の +時間 は、ふつうのえさの ボーナス（1日4回）とは べつ枠。love で 1日の そだち が 約2割 ふえる くらい。
- **おなか は増えない。えさやりのコイン・なつき（えさ）・ミッション feed にも数えない**（ふつうのえさの かわりには ならない）。
- ヒントは 水温・水・おなか の原因を先に出す。ビタミンは「なおる とちゅうを はやめる」もの（h_weak_vitamin は 原因が もう無いときだけ）。

### 3-3. ぷいっ（dislike）の見せ方
- `aq.react(uid, 'turn')`：ビタミンの粒の前で **0.5〜1秒だけ くるっと横を向いて**、ふつうに泳いでいく。小さな ♪ マーク（3D水槽係へ：新しいリアクション。まだ無ければ 何もしない）。
- 悲しい顔・涙・ばつ印・暗くなる・逃げる・沈む・失敗の音 は使わない。ごきげん は下げない。追いかけて食べさせる操作も無い。好き嫌いは「その子の こせい」として見せる。
- ふきだし：その しゅるいで はじめて ぷいっ としたときだけ `VITAMIN_LINES.dislike`（「{name}は ぷいっ！ いつもの ごはんが すきなんだね。」）。2回目からは ふきだし なし。
- dislike の魚も、ふつうのえさ・なでる で 同じように育つ（ビタミンは 早めるだけ）。ふつうのえさ・なでる の よろこび方を じゅうぶん うれしそうに。

### 3-4. 好き嫌いの知らせ方
- 図鑑：魚のページに「ビタミン：だいすき／たべる／いつもの ごはんが すき」（`VITAMIN_DEX`）。えさの絵で区別し、赤い × や 悲しい顔は使わない。
- お店：魚の札にも 同じ表示（買う前に分かる。がっかりを防ぐ）。ビタミンの説明（desc）に「すききらいが あるよ」。
- ふきだし：love の魚が食べたら いちばん よろこんだ1匹に `VITAMIN_LINES.love`、ok だけなら `ok`。

### 3-5. 好き嫌い（fish.js の vitamin）
- love 12種：グッピー、キンギョ、ミナミヌマエビ、ベタ、レッドビーシュリンプ、プラティ、チェリーバルブ、ドワーフグラミー、ルリスズメダイ、カクレクマノミ、スカンクシュリンプ、ナンヨウハギ
- ok 9種：メダカ、ネオンテトラ、コリドラス、アルビノコリドラス、エンゼルフィッシュ、ラムズホーン、ラミーノーズテトラ、ハタタテハゼ、キイロハギ
- dislike 4種：イシマキガイ、オトシンクルス、シッタカガイ、ニシキテグリ（こけや ライブロックの 小さな いきものを 食べる なかま）

## 6. v0.2 のセーブからの移行

- 貝の space が 0 になるので、v0.2 で貝がいた水槽は 空きが ふえる（問題なし）。
- 魚・エビが7匹以上（エビが多い）や 貝が3匹以上いるセーブ：**そのまま残す**（へらさない）。新しく買えるのは 上限より少なくなってから（v0.3 では手放せないので、実際には そのまま）。
- `tank.thermo` が無ければ 'normal'。`tank.feederOn` が無ければ true。ビタミンの残り `state.inv.food_vitamin` が無ければ 0。1日のビタミン `daily.vitamin[tankId]` が無ければ 0。図鑑の「はじめての ぷいっ」 `dex[id].vitaminTried` が無ければ false。
- CLEAN_FLOOR が v0.1 の水槽にも かかるので、ずっと 100 だった水槽は 少しずつ よごれるようになる（水かえで もどる）。
- 解放の判定は変わらない。

## 7. 実装係への注意

- 魚・エビの上限は「6匹」と「space 6」の両方。貝は space 0 で、べつに2匹。canBuyFish に足す。
- 自動えさやりは「整数の時刻をまたいだとき」にまとめて判定（8時・18時）。
- ビタミンは「1日1回／水槽」と「残り回数」の2つで止める。全員 dislike なら減らさない。
- おんど ダイヤルはヒーターとファンが両方あるときだけ。危ない段は選べない。「とても ぴったり +5」は ダイヤルが無い水槽でも計算する。
- CLEAN_FLOOR は 水槽の きれいさ の変化を計算した最後に `min(変化, −0.4)`（魚・エビがいるときだけ）。
- 絵がまだ無いもの（デザイン係へ）：アイコン food_vitamin・auto_feeder・fan・co2_kit・skimmer。3D水槽係へ：4つの器具の形と 'turn' リアクション。音楽係へ：ビタミン（love）の よろこびの音、ぷいっ は かるい「ぽよん」くらい（悲しい音・失敗の音は使わない）。
