# 設計の約束ごと（係どうしの取り決め）

まとめ役（Claude本体）が決めた土台。変えたいときは勝手に変えず、まとめ役に理由を添えて提案する。

## 技術
- ビルドなしの静的サイト。`<script type="module">` の ES モジュール。npm 依存なし。
- 3D は Three.js r170（`vendor/three.module.min.js` を相対 import。CDN 禁止）。
- 保存は localStorage（キー `osakana-room-save-v1`）。通信は一切しない。
- 横持ち前提。基準の画面サイズは 740×390（スマホ横）と 1024×768（iPad横）。どちらでも崩れないこと。
- 文字はひらがな・カタカナ。漢字を画面に出さない（コード・コメントは日本語の漢字でよい）。
- 改行コードは LF。

## データの形（js/data/）
```js
// js/data/fish.js
export const FISH = [{
  id: 'medaka',            // 英小文字。画像ファイル名にも使う
  name: 'メダカ',          // ひらがな・カタカナ
  kind: 'fish',            // 'fish' | 'shrimp' | 'snail' など
  water: 'fresh',          // 'fresh' | 'salt'
  rarity: 1,               // 1〜5（1=ふつう … 5=でんせつ）
  price: 50,               // お店の値段（コイン）。売っていないものは null
  temp: { min: 18, max: 28, best: 24 },   // 水温（℃）
  food: ['flake'],         // 食べる餌の id
  growDays: [2, 6],        // ちびっこ→おとな、おとな→ビッグ に必要な「よく育った日数」
  sizeCm: [1.5, 3, 4],     // ちびっこ／おとな／ビッグ の全長
  swim: { layer: 'top', speed: 1.0, school: true },  // 泳ぐ高さ top|middle|bottom|any、速さ倍率、群れるか
  look: { lengthToHeight: 4.0, thickness: 0.18, finStyle: 'normal' },  // 3D の体形
  texture: 'assets/fish/medaka.png',      // 横から見た絵（透過PNG、頭が右）
  intro: 'にほんの おがわに すむ ちいさな さかな。',  // 図鑑の説明
  hint: 'みずの うえの ほうを およぐよ。',
}];
// js/data/items.js : 器具・餌・飾り
export const ITEMS = [{ id, name, type: 'heater'|'filter'|'air'|'waterchange'|'decor'|'food'|'light', price, effect: {...}, icon: 'assets/items/<id>.png', desc }];
// js/data/compat.js : 相性
export const COMPAT = { 'medaka|guppy': 1, ... };   // 2=なかよし 1=ふつう 0=にがて（キーは id を辞書順に並べて | でつなぐ）
```

## 3D水槽のAPI（js/aquarium/index.js）
部屋・ゲーム係はこの関数だけを使う。中身は3D水槽係の自由。
```js
import { createAquarium } from './aquarium/index.js';
const aq = createAquarium(canvasElement, { water: 'fresh' });
aq.setFish([{ uid, speciesId, stage /*0,1,2*/, health /*0-100*/, happy /*0-100*/ }]);  // 何度呼んでもよい（差分で更新）
aq.setDecor(['stone', 'liverock', ...]);  // 入っている飾り・器具の id
aq.setWater({ dirt /*0-1 にごり*/, waste /*0-1 そこの ごみ（そうじで 0）*/, bubbles /*bool*/, light /*0-1*/ });
aq.feed(xNorm, yNorm);     // 画面上の位置（0-1）に餌を落とす
aq.react(uid, type);       // 'heart' | 'jump' | 'spin' | 'happy' | 'sad' | 'thanks' | 'sleepy'
aq.on('eat', ({ uid }) => {});      // 魚が餌を食べた
aq.on('tapFish', ({ uid }) => {});  // 魚をタップした
aq.screenPosOf(uid);       // → { x, y }（CSSピクセル）。吹き出し・ハートのDOM用
aq.start(); aq.stop(); aq.dispose();
```
- 元気がない魚（health が低い）は、ゆっくり泳ぐ・底のほうでじっとする・色が少しくすむ。**ひっくり返す・浮かせるは禁止。**
- `speciesId` の絵が assets/fish/ にまだ無いときは、体形データから仮の魚を作って表示する（絵が届いたら自動で差し替わる）。

## 時間（js/state.js）
- 開いている間だけ進む。`document.visibilityState !== 'visible'` の間は止める。閉じていた間を取り戻す計算はしない。
- ゲームの1日 ＝ 現実の 600 秒。
- 数値の変化は sim.js の `tick(state, gameMinutes)` に集める（テストしやすくするため）。
