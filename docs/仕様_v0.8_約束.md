   - どうぐ：ペン（ふとさ 3つ）・いろ（16しょく くらい）・けしゴム・ぬりつぶし・ひとつもどす・ぜんぶけす。**ぜんぶけす は「ほんとうに ぜんぶ けして いい？」の かくにんを 1かい 出す。**
   - さいしょに「もとに する いきものを えらぶ？」：

     - **えらばない（オリジナル）**：じゆうに かく。かいた 絵は **ひらたい いた** の まま およぎ、むきを かえると 左右が はんてん。
   - **2026-11-20 追加（本人）**：ぬりえ でも ベタぬり だけで なく、**ほそい ペンで ぬった 色の 上から ちがう 色で もようや 字（じぶんの なまえ など）を かける**。ペンは いちばん ほそい（字が かける）ものを ふくめる。ぬりえ でも オリジナル でも おなじ どうぐ。
     - 字が はんたいに 見えないように：おえかき係は「もじ」モード（もじペン）を つける。もじペンで かいた ものは べつの そう `f.dream.overlay`（art と おなじ 大きさの すける PNG。なければ 省く）に 入れる。3D係は overlay を、どちらの むき・どちらの がわ から 見ても 字が ただしく よめるように はる（うらがわ・ぎゃくむき では overlay だけを その はんいの 中で 左右 もどす）。
   - かいた あと えらぶ：しゅるい（さかな／エビ・カニ／カエル／カメ・トカゲ。ぬりえ の ときは もとの いきもの から きまる）・はやさ（ゆっくり／ふつう／すばやい）・おおきさ（ちいさい／ふつう／おおきい）・なまえ（ひらがな）。
   - うごき：さかな＝みずの 中を およぐ。エビ・カニ＝そこを あるく。カエル＝りくで ぴょんと はね、みずでは およぐ。カメ・トカゲ＝りくを あるき、みずでは ゆっくり およぐ。
   - すいそうの かたち：「みずだけ」「はんぶん りく」を えらべて、いつでも かえられる。
   - 1つの すいそうに 6ぴき まで（いまと おなじ）。
   - **本人と きめた こと**：①入れかえは いまの おやすみすいそう に しまう（かいた いきものは ゆめのすいそう にだけ もどせる）。②ゆめのすいそう に 入るのは かいた いきもの だけ。③おせわは ふつうに ある（えさ・なでる・ハート・コイン）。おおきさは えらんだ まま そだたない。④かいた 絵は「えに もどす」で けして かきなおせる（かくにん 1かい。「しぬ」を 思わせる ことばは つかわない）。⑤ゆめのすいそう も そうこに しまえる。

## データの 形（変えない）
### 水の しゅるい
- `WATERS.dream = { name: 'ゆめ', items: ['fresh','both'] }`（ゆめ係）。すいそう：`t.water === 'dream'`、`t.layout = 'water' | 'land'`（はじめ 'water'）。`t.layout` は ゆめのすいそう だけ つかう（いけは いままで どおり いつも りく あり）。
- state.js の migrate で 'dream' と layout が きえない こと。

### ゆめの いきもの
- fish.js に しゅるいを 4つ：`dream_fish`（さかな）・`dream_crab`（エビ・カニ）・`dream_frog`（カエル）・`dream_reptile`（カメ・トカゲ）。`water: 'dream'`、`obtain: 'dream'`、`price: null`、`hidden: true`。おみせ・ずかん・ずかんの かず・ミッションの かず・クイズ・つり/ガサガサ・あいしょう から はずす。
- 魚の きろく は ふつうの 魚と おなじ（`sim.createFish` で つくる。`addDex` は よばない）＋ `f.dream`：
  ```js
  f.dream = {
    art: 'data:image/png;base64,…', // すける PNG。真横・頭は assets/fish の 絵と おなじ むき。よけいな すきまを けずって 長い 辺 512px いか
    overlay: 'data:image/png;base64,…' | undefined, // もじペンの そう（art と おなじ 大きさ・いち）。ないことも ある
    base: 'medaka' | null,          // ぬりえ の もとの しゅるい。null＝オリジナル（ひらたい いた）
    kind: 'fish' | 'crab' | 'frog' | 'reptile',
    speed: 'slow' | 'normal' | 'fast',
    size: 's' | 'm' | 'l',
    name: 'ぴょんきち',               // ひらがな・カタカナ 8もじ まで。から なら しゅるいの なまえ
    made: 5                          // かいた ゲームの ひ
  }
  ```
  `speciesId` は `'dream_' + kind`（ゲームの しくみ用）。見た目と うごきは `f.dream` を 3D係が 見る。ぬりえ の ときの kind は もとの いきもの から ゆめ係の `dream.kindOf(baseId)` で きめる（エビ・カニ・ザリガニ・貝 → crab、カエル → frog、カメ・スッポン・イモリ・トカゲ → reptile、ほか → fish）。
- ゆめ係が 用意する（js/dream.js、sim.js から 再輸出）：
  - `dream.canAdd(state, t)` → `{ ok, reason }`（ゆめのすいそう か・6ぴき いか・ぜんぶで の かず いか）
  - `dream.addCreature(state, t, dreamInfo)` → 新しい 魚（`f.dream` つき）
  - `dream.release(state, t, uid)`（えに もどす）
  - `dream.setLayout(state, t, 'water'|'land')`
  - `dream.baseChoices(state)` → ぬりえ に えらべる しゅるい id の 配列（ずかんに のっていて 絵の ある もの。ゆめ用 4つ と premium で もっていない もの は のぞく）
  - `dream.kindOf(speciesId)`
  - `DREAM.maxCreatures`（ゆめの いきもの ぜんぶ＝すいそう＋おやすみすいそう の 上限。localStorage の 大きさの ため。30 くらい）
- 大きさ：`sim.sizeOf(f)` は ゆめの いきもの では `size` から（s 3cm・m 6cm・l 10cm くらい。ゆめ係が きめる）。そだたない（stage は おとな で とめる）。
- おせわ：おなか・なでる・ハート・ありがとう・コインは ふつうの 魚と おなじ。きれいさ・すいおん・くうき は ゆめのすいそう では いつも ちょうど よい（ふしぎな すいそう。器具なし で だいじょうぶ）。

### おえかき がめん（おえかき係 → ゆめ係）
- `G.addScreen('draw', { show(G, { tankId }), hide(G) }, { sheet: false })` で とうろく（がめん いっぱい）。main.js の よみこみ一覧に `./ui/draw.js` を 足すのは おえかき係。
- すいそう がめんの「いきものを ついか」（ゆめ係）は `G.show('draw', { tankId })` を よぶ（G の 名前は main.js を 見て あわせる）。
- できあがったら おえかき係が `sim.dream.addCreature(state, t, dreamInfo)` → セーブ → すいそう がめんに もどる。
- ぬりえ の もとの 絵：`assets/fish/<id>.png`（speciesDefaults の spec.texture）。すける ところ が そと、ぬれる ところ が 中。キャンバスは 横長、横持ち 740×390 でも つかえる 大きさの どうぐ。指でも ペンでも（pointer events）。

### 3D（3D係）
- 魚の 一覧を うけとる ところで `f.dream` が あれば：
  - `base` あり：`base` の しゅるいの spec（swim・厚み・round など）を つかい、絵だけ `art` に して 立体を 作る（いまの 輪郭→ふくらませる しくみ）。uid ごとに キャッシュ、すいそうから いなく なったら dispose。
  - `base` なし：`art` を はった ひらたい いた（DoubleSide）。むきで 左右 はんてん。kind で うごき：fish＝ふつうに およぐ、crab＝そこを あるく（crawl）、frog＝りくで ぴょん・みずでは およぐ、reptile＝りくを あるく・みずでは ゆっくり（'land' の しくみを つかう）。
  - `speed`：slow ×0.6・normal ×1・fast ×1.6 くらい。`size`：s・m・l で 見た目の 大きさ。
- ゆめのすいそう：`layout === 'land'` なら いけの すいそうの りくち と おなじ しくみで みぎ 40% くらいを りくに。'water' なら りく なし。りくが ない とき frog・reptile は みずの 中と そこで すごす。いろは ゆめっぽく（うすい むらさき〜みずいろ の やさしい ひかり。きらきら すこし）。
