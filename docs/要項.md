# おさかなルーム（仮）要項

2026-11-07 本人からの聞き取り。ここに書いたことが最優先。迷ったらここに戻る。

## どんなゲームか
- 自分の部屋で、魚・エビなど水の生きものを水槽で飼って育てる、ゴールのないほのぼの育成ゲーム。
- はじめは部屋にベッドと空の水槽が1つだけ。お店で魚を1匹買い、チュートリアルで石・ブクブク・ヒーター・水かえ道具などをそろえて、水槽を魚に合った形にしていく。
- 餌をあげてぐんぐん大きくする。水槽を見る画面では、画面いっぱいの水槽を魚がゆったり泳ぎ、手元のボタンで餌やりなどをする。
- 部屋がいっぱいになったら、次の部屋を借りたり、部屋を広げたりできる（後の版）。

## 大事な決まり
1. **魚は死なない。** どんなに弱っても「げんきがない」で止まる。死を連想させる表現（ひっくり返る、浮く、骨、お墓など）は使わない。元気にする方法をヒントで教える。
2. **通信しない。** データは端末の中だけに保存する。外部サーバー・広告・解析・課金はなし。外部 CDN も読み込まない（ライブラリは vendor/ に同梱）。
3. **小さい子が遊ぶ。** 文字はひらがな・カタカナ中心。漢字は使わない。
4. **時間はアプリを開いている間だけ進む。** 閉じている間・裏に回っている間は止まる（放っておいても魚がかわいそうにならない）。開いている間は **ゲームの1日 ＝ 現実の10分**。
5. 課金なし。ガチャはゲーム内のチケットやコインだけ。

## 形
- Web アプリ（PWA）。公開リポジトリ akihikoito-apps/osakana-room、GitHub Pages で配る。スマホ・iPad で遊んで確かめる。
- **横持ち**。縦にされたら「よこに してね」と出す。
- **リアルな魚を 3D で**。水槽の奥行きを使って泳ぐ。リアルな見た目でも、反応はアニメのように（餌で喜ぶ、ハートが出る、くるっと回る、ジャンプなど）。

## 魚と水槽
- 実在の生きものの名前を使う。レア度あり（珍しいエビや魚を運よく手に入れて、友だちに自慢できる）。
- 淡水水槽と海水水槽を分ける。はじめは淡水。海水は途中で解放（ライブロックなど海水用の器具が増える）。
- 最初の版は8種類くらい、のちに50種類以上。
- 入手方法：購入・釣り・もらうイベント・ガチャ（購入以外は後の版）。

## 育てるときの数値（画面で見えるようにする）
- 基本の4つ：**すいおん**（水温）、**きれいさ**（水のきれいさ）、**くうき**（酸素）、**おなか**（餌）
- 追加：
  - **なかよし**：いっしょの水槽の魚どうしの相性（相性表を持つ）
  - **なつき**：飼い主へのなつき度（魚ごと）
  - **ごきげん**：その水槽をどれくらい気に入っているか（魚ごと）
  - **けんこう**：弱っているか、いないか（魚ごと）
- 育ち方は3段階：ちびっこ → おとな → ビッグ。卵・赤ちゃんは後の版。

## お金
- 課金なし。ゲーム内コインで器具・魚・餌を買う。
- かせぎ方：
  - バイト（ミニゲーム型）／ミニゲーム（後の版）
  - **ミッション**クリアでごほうび
  - **お世話をすると少しもらえる**（餌やり・水かえなど）
  - **魚が喜んで「ありがとう」をしてくれるともらえる**
  - → 育ててあげたい気持ちにつながるように、お世話の行動にお金がつく
- ガチャはゲーム内チケット（毎日のログイン・釣りなどでもらう）。

## 自慢
- 図鑑のコンプリート率。
- 写真モード（水槽をきれいに撮ってスクショで見せ合う）。レアな魚はキラキラの枠。

## 最初の版（v0.1）の範囲
部屋1つ（ベッドと空の水槽）→ お店で魚を1匹買う → チュートリアルで石・ブクブク・ヒーター・水かえ道具をそろえる → 餌やりで大きくなる → 数値と元気度とヒント → 魚のリアクション（ハートなど）→ お世話でコイン・かんたんなミッション → セーブ。
ここまで遊べる形で Pages に載せ、本人に触ってもらってから、釣り・ガチャ・バイト・部屋の拡張を順に足す。
