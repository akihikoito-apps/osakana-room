# 相性表（v0.1・淡水10種）

企画・図鑑係。データの本体は `js/data/compat.js`（この表はそこから作った）。

- ◎＝なかよし（2）、○＝ふつう（1）、×＝にがて（0）。表に無い組み合わせは ふつう。
- 同じ種類どうしも数える（対角線）。ベタどうしは × 。
- 効果：なかよし値（0→20、1→60、2→100 の平均）、ごきげん（◎1匹 +5 最大+10、×1匹 -10 合計 -20 まで）。**けんこう には効かない**（v0.1 は魚を手放せないので、直せない理由で弱らせない）。お店で × の相手がいる魚を選ぶと たしかめの ことばを出す（買うのは止めない）。

## 決めた理由（要点）
- キンギョ：体が大きく小さい魚やエビを追いかける・好きな水温も低め → キンギョどうし以外は ×。ただしメダカとは日本でよくいっしょに飼われるので ○。チュートリアルの最初の魚の候補からは外した。
- エンゼルフィッシュ：ネオンテトラ・メダカ・エビなど口に入る大きさの相手は ×。コリドラスとは ◎。
- ベタ：ベタどうし・ひれの長いグッピー・エビは ×。
- コリドラス・アルビノコリドラス・ミナミヌマエビ：おだやかで、ほとんどの相手と ◎／○（キンギョだけ ×）。
- メダカとミナミヌマエビ：どちらも日本の小川の生きもので ◎。
- グッピー・ネオンテトラ・コリドラス：定番の組み合わせで ◎。
