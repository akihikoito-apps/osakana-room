# 相性表（v0.2）

企画・図鑑係。データの本体は `js/data/compat.js`（この表はそこから作った）。

- ◎＝なかよし（2）、○＝ふつう（1）、×＝にがて（0）。表に無い組み合わせは ふつう。
- 同じ種類どうしも数える（対角線）。
- 効果：なかよし値（0→20、1→60、2→100 の平均）、ごきげん（◎1匹 +5 最大+10、×1匹 -10 合計 -20 まで）。**けんこう には効かない**（魚を手放せないので、直せない理由で弱らせない）。お店で × の相手がいる魚を選ぶと たしかめの ことばを出す（買うのは止めない）。
- 淡水と海水は同じ水槽に入らないので、組み合わせは無い。

## 決めた理由（要点）
- キンギョ：体が大きく小さい魚やエビを追いかける・好きな水温も低め → キンギョどうし以外はほぼ ×。メダカとは日本でよくいっしょに飼われるので ○。かい とは ○。
- エンゼルフィッシュ：ネオンテトラ・ラミーノーズ・メダカ・エビなど口に入る大きさの相手は ×。コリドラスとは ◎。
- ベタ・ドワーフグラミー：オスどうし・にた なかまどうしは ×。エビを たべようとするので エビとも ×。
- コリドラス・オトシンクルス・ミナミヌマエビ・かい：おだやかで、ほとんどの相手と ◎／○。
- グッピー・プラティ・ネオンテトラ・ラミーノーズ・チェリーバルブ・コリドラス：定番の組み合わせで ◎。
- 海水：ハギ（キイロハギ・ナンヨウハギ）どうし、ルリスズメダイどうし、ニシキテグリどうしは ×。ルリスズメダイは ハタタテハゼ・ニシキテグリを追いかけるので ×。スカンクシュリンプ（おそうじエビ）は だれとでも ◎。
