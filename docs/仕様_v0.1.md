# 仕様 v0.1（企画・図鑑係）

実装係がそのままコードにできるように、数値と手順を書く。**数値の本体は `js/data/balance.js`**（器具の効果は `items.js`）。この文書の数字とデータが食い違ったらデータが正しい（直すときは両方）。

- データファイル：`js/data/fish.js` `items.js` `compat.js` `balance.js` `missions.js` `hints.js` `tutorial.js`。すべて `export const` の ES モジュール。node で import できることを確認ずみ。
- 画面に出す文字（name / intro / hint / desc / title / text / say / LABELS）は**ひらがな・カタカナだけ**。点検で漢字が無いことを確認ずみ。
- 絶対の決まり：魚は死なない／通信しない／ひらがなカタカナ／アプリを閉じている間は時間が止まる。

## 1. 時間

| 項目 | 値 |
|---|---|
| ゲームの1日 | 現実 600 秒（10分） |
| ゲームの1時間 | 現実 25 秒 |
| 1 現実秒 | ゲーム 2.4 分 |
| はじめて遊んだときの時計 | 6:00 |
| 「1日」の区切り | ゲーム時計の 6:00。1日あたりの上限（コイン・なつき・えさボーナス）はここで 0 に戻す |
| チュートリアル中 | **時計を止める**（`TIME.stopDuringTutorial`） |

- `sim.tick(state, gameMinutes)`：下の「1時間あたり」の値に `gameMinutes / 60` を掛けて足す。tick は細かくても粗くても結果がほぼ同じになるようにする。
- **確率の判定（ありがとう・夜の sleepy）と「よい時間」の数え上げは、ゲーム時計が整数の時刻をまたいだときに1回ずつ**行う。フレームごとに確率を振らない。開き直しで引き直せないように、判定ずみの時刻を保存する。

## 3. 1時間あたりの変化（tick の中身）

以下 `S` = 水槽の魚の space の合計、`n(id)` = 水槽に入っているその id の数、`F` = フィルターがあれば 0.5 なければ 1、`L` = ライトがあれば 1.5 なければ 1。

### 3-1. すいおん
- ヒーターあり：25℃ に向けて 1℃/時間 近づく（行きすぎない）。
- ヒーターなし：へやの温度（v0.1 は 20℃ 固定）に向けて 0.5℃/時間 近づく。
- チュートリアルでヒーターを受け取ったら、すいおん を**すぐ 25℃** にする（時計が止まっているため。`TUTORIAL.heaterWarmsNow`）。
- 判定（魚ごと）：
  - **ぴったり**：`|すいおん − best| ≤ 2`
  - **はんい内**：`min ≤ すいおん ≤ max`
  - **はんい外**：それ以外。`min − 3` より下か `max + 3` より上は「とても」
- 25℃ は 淡水10種すべての はんい内。ぴったりでない魚もいる（ベタ best 27 は ぴったり、レッドビー best 23 は ぴったり、など）。v0.1 では「あつい」は起きない。

### 3-2. きれいさ
```
よごれ = (0.3 + 0.4×S + 1.5×たべのこし) × F
きれいさ += −よごれ + 0.2×n(plant)×L
```
- 例：メダカ1匹・フィルターなし → −0.7/時間（1日 −17）。4匹 → −1.9/時間（1日 −46）。4匹＋フィルター → −0.95/時間（1日 −23）。
- フィルターは「よごれる速さを半分」にする（0 にはしない）。フィルターを入れても ときどき水かえが要るので、水かえのコインが無くならない。
- **みずかえ**（道具 water_change）：きれいさ +40（100 まで）、たべのこし = 0。何回でもできる。
- **そうじ**（無料のボタン。あみで すくう）：たべのこし = 0 にするだけ。きれいさ は増えない。コインもない。たべのこし が 0 のときはボタンを灰色に。

### 3-3. たべのこし
- えさを落としたとき、**食べなかった魚（おなか ≥ 90）が半分以上いたら** たべのこし +0.5（最大 5）。
- **全員が おなか ≥ 90 なら、えさは落とさない**。ふきだし「みんな おなか いっぱい みたい。また あとで あげてね。」（`FULL_LINE`）。コインも出ない。
- 減り方（/時間）：`0.2×n(filter) + 0.125×(そうじやの魚の数)`。そうじやの魚＝ corydoras, albino_corydoras, minami_shrimp, red_bee_shrimp（`CLEAN.cleanerIds`）。
- 画面：aq.setWater の dirt に `(100 − きれいさ) / 100`。

### 3-4. くうき
```
くうき += (くうき < 60 ? 0.6 : 0) − 0.5×S + 3×n(air_pump) + 0.5×n(filter) + 0.8×n(plant)×L
```
- 例：メダカ1匹・ブクブクなし → 60 付近で落ち着く。4匹・ブクブクなし → −1.4/時間。ブクブクがあれば満員（S=6）でも 上がる。
- aq.setWater の bubbles は ブクブクがあるとき true。

### 3-5. おなか（魚ごと）
- 減り方：`−3.5 × appetite`（/時間）。メダカ −2.8、ネオン −2.8、キンギョ −3.85、エビ −1.75。0 で止まる。
- えさやり：えさボタンで `aq.feed(x, y)`。水槽の `eat` イベントで、**その魚が おなか < 90 なら** おなか +30（100 まで）。**1回のえさやりで1匹1回だけ**（2回目の eat は数えない）。ハートは水槽が自動で出す。
- 1回のえさやり ＝ ボタンを押してから 現実 5 秒。その間ボタンは押せない（`HUNGER.feedLockRealSec`）。
- 目安：1日（10分）に 2〜3 回。

### 3-6. けんこう（魚ごと）
1時間ごとに「わるいこと」を足す（同じ行は重いほうだけ）。**合計は −3/時間 まで**。

| わるいこと | 条件 | /時間 |
|---|---|---|
| さむい | すいおん が はんい外 | −2（「とても」なら −3） |
| よごれ | きれいさ < その魚の cleanMin（ふつう 40、レッドビー 60） | −1.5（きれいさ < 20 なら −3） |
| くうきが すくない | くうき < 30 | −2（< 15 なら −3） |
| ぺこぺこ | おなか < 10 | −1.5 |
| にがて | v0.1 は けんこう に効かない | 0 |

- わるいことが**1つも無い**：+4/時間。さらに「ぜんぶ ぴったり」（すいおん ぴったり・きれいさ ≥ 70・くうき ≥ 50・おなか ≥ 30）なら +6/時間。
- **けんこう は 10 より下がらない**（tick の最後で必ず `max(10, …)`）。100 より上がらない。
- **「げんきが ない」（よわっている）＝ けんこう < 40**。「げんき」＝ 70 以上。
- 手当てすると 10→40 まで 約8時間（現実 3分）。

### 3-7. ごきげん（魚ごと）
目標値を計算して、1時間に 5 ずつ近づける（行きすぎない）。
```
目標 = 50
  + すいおん（ぴったり +15／はんい内 0／はんい外 −20）
  + きれいさ（≥70 +10／<40 −15）
  + くうき（≥50 +5／<30 −15）
  + おなか（≥50 +5／<20 −15）
  + すきな飾り：fish.likes のタグの飾り（items.js の tag）が水槽にあれば 1しゅるい +5（最大 +15）
  + なかよし：相性2 の相手 1匹 +5（最大 +10）
  + にがて：相性0 の相手 1匹 −10（合計 −20 まで）
  + ライトがある +5
→ 0〜100 におさめる
```
- 「ごきげん」＝ 70 以上、「しょんぼり」＝ 30 未満。
- 例：チュートリアル直後のメダカ（25℃ ぴったり・きれい・くうき70・おなか60・いし は好きではない）→ 50+15+10+5+5 = 85。

### 3-8. なつき（魚ごと）
| きっかけ | 増え方 | 1日の上限 |
|---|---|---|
| おなか < 80 のときに えさを食べた | +2 | 5回 |
| 魚をタップ（なでる） | +1 | 5回（同じ魚は 現実30秒あける） |
| みずかえ（きれいさ < 85 のとき） | 全員 +1 | 2回 |
- **なつき は減らない。** 見せ方：ハート 0〜5 こ（20 ごとに1こ）。

### 3-9. なかよし（魚ごと・計算だけ）
- 同じ水槽の**ほかの魚全員**との相性（`compatOf(a, b)`、同じ種類どうしも数える）を 0→20、1→60、2→100 にして平均。
- 1匹だけ：50。1匹だけで `swim.school: true` の魚：40（ヒント h_lonely）。
- 表は docs/相性表.md。

## 4. 成長（そだち ゲージ）

日ごとの合格・不合格はやめて、**ためていく形**にした（失敗した日があっても積み上げが残る。小さい子が短い時間で遊んでも進む）。

- そだち +1：ゲーム1時間ごとに「よい時間」なら（おなか ≥ 20 かつ けんこう ≥ 60 かつ すいおん が はんい内）。
- そだち +2：えさを食べて おなかが増えたとき（1日4回まで）。「えさで ぐんぐん育つ」。
- 必要な量：ちびっこ→おとな ＝ `growDays[0] × 20`、おとな→ビッグ ＝ さらに `growDays[1] × 20`。そだちは減らない。
- 成長したら：リアクション jump → 1秒後 happy、ふきだし「{name}が おおきく なったよ！」、aq.setFish の stage を更新、そだち は 0 から数え直し。
- 魚のカードに「そだち」の小さなゲージ（次の段階までの割合）を出す。

## 9. チュートリアル（tutorial.js）

- はじめは部屋に ベッドと空の水槽だけ。**12 ステップ**。話し手は「おみせの ひと」。時計は止める。
- 流れ（魚を早く見せてから、道具をそろえる）：

| # | 内容 | 待つもの |
|---|---|---|
| 1 | あいさつ →「おみせ」へ | お店を開く |
| 2 | 最初の魚を1匹（メダカ・グッピー・ネオンテトラ。メダカに「おすすめ」） | 魚を買う |
| 3 | 魚が来た。えさをもらう → 水槽へ | 水槽の画面 |
| 4 | えさをあげる | 魚が食べる |
| 5 | ハートの説明・なでられる | タップ |
| 6 | 道具をそろえよう（プレゼント）→ お店へ | お店を開く |
| 7〜10 | いし → ブクブク → ヒーター → みずかえセット を「うけとる」 | それぞれ受け取る |
| 11 | かおマークの説明 | タップ |
| 12 | コインとヒントの説明・おわり（+50） | タップ |

- `lockOthers: true` のステップは、光らせた所以外を押せない（まわりを少し暗く）。
- 受け取った いし・ブクブク・ヒーター は すぐ水槽に入る（setDecor）。ヒーターを受け取ったら すいおん は すぐ 25℃。
- 途中でアプリを閉じたら、次はそのステップから。
- セリフは tutorial.js の `say`（1回2行まで）。`{name}` は買った魚の名前。

## 10. ヒント（hints.js）

- 判定は ゲーム1時間ごと と お世話・買い物の直後。当てはまるもののうち `priority` が小さい1つだけを、画面のすみの ふきだしに出す。
- **げんきが ない魚がいるとき**は、そのヒントの前に `WEAK_PREFIX`（「{name}は すこし やすんでいるよ。」）をつける。原因のヒントとボタンは そのまま出る（原因が隠れない）。
- げんきが ない魚の原因が全部直ったら `RECOVERING_LINE`（「すこしずつ げんきに なっているよ」）、けんこう 40 以上に戻ったら `RECOVERED_LINE`。
- 同じヒントは、閉じてから ゲーム3時間は出さない。お世話で原因が直ったら すぐ消す。
- `action` のボタンを ゆっくり光らせる（'shop' 'water_change' 'scoop' 'feed'）。
- 当てはまるものが無いときは ときどき `HAPPY_LINES`（ほめる ひとこと）。
- 言い方の決まり：責めない（「〜しなかったから」「〜しすぎ」と言わない）。してほしいことを1つだけ、前向きに言う。「しぬ」「びょうき」「くるしい」「ふるえる」は使わない。1回2行まで。
- `{like}` は その魚の likes の最初のタグで、水槽に まだ無いものの items.js の name（例：「みずくさ」）。

## 11. 魚のリアクション

`aq.react(uid, type)`。**餌を食べたときのハートは水槽が自動で出す**（ここでは扱わない）。

| きっかけ | type | 決まり |
|---|---|---|
| 魚をタップ | なつき < 40：happy／40〜79：heart／80 以上：spin | 同じ魚は 現実3秒に1回。けんこう < 40 の魚は sleepy |
| ありがとう | thanks | 7-3 |
| 成長した | jump → 1秒後 happy | 4章 |
| げんきに戻った（けんこう 40 以上） | happy | 10章 |
| みずかえ | 全員 happy、1匹だけ spin | |
| すきな飾りを入れた | その飾りが好きな魚が spin | |
| なかよし（相性2）の新しい魚が来た | 来た魚と相手が heart | |
| ごきげん ≥ 80 の魚がいる | 4時間に1回、1匹が jump か spin | 何もしなくても楽しそうに |
| おなか < 30 か ごきげん < 30 | 3時間に1回 sad | やわらかく。音は出さない |
| けんこう < 40 | 5時間に1回 sleepy | ふきだし「すこし やすんでいるよ」の意味 |
| 夜（22時〜6時） | 1時間ごと 20% で sleepy | |

## 12. 元気がない魚の見せ方

- けんこう < 40（げんきが ない）：
  - 水槽係に health を渡す → **ゆっくり泳ぐ（ふだんの 50〜70%）・石や水草のそばで休む・色は ほんの少しだけ くすむ（彩度 −10% くらいまで）**。ひれは動かし続け、タップには反応する（完全に止めない）。
  - 5時間に1回 sleepy。
  - 魚のカードに「げんきが ない」と 青っぽい しずくの マーク（赤や ✕ は使わない）。
  - ヒントは WEAK_PREFIX ＋ 原因のヒント（10章）。
- **ひっくり返る・浮く・横になる・底に沈んで動かない は禁止。** 骨・お墓・天使の輪・大きな涙・点滅・苦しそうな音も使わない。
- けんこう 40 以上に戻ったら：happy を1回、`RECOVERED_LINE`。

## 13. 数値の見せ方（LABELS）

- 小さい子には数字ではなく**3段階の かお**（にこにこ／ふつう／しょんぼり）＋ みじかい ことば（balance.js の LABELS）。
- **いつも出すのは きほんの4つ**（すいおん・きれいさ・くうき・おなか。おなか は水槽の中で いちばん すいている魚の値）。けんこう・ごきげん・なつき・なかよし・そだち は魚をタップしたカードで。
- すいおん だけは「25ど」と数字も出してよい。コイン・値段は数字。0〜100 の数字は図鑑の「くわしく」だけ。
- 境目：きれいさ 70/40、くうき 50/30、おなか 70/30（90 以上は「おなか いっぱい」）、けんこう 70/40、ごきげん 70/30、なかよし 80/40。すいおん は ぴったり＝ちょうどいい、はんい内＝まあまあ、下＝さむい、上＝あつい。
- なつき は ハート 0〜5。成長は ちびっこ／おとな／ビッグ。

## 14. セーブ

- localStorage `osakana-room-save-v1`（設計.md）。保存するもの：コイン、時計（判定ずみの時刻を含む）、水槽（すいおん・きれいさ・くうき・たべのこし・入っている id）、持っている道具、魚（uid・speciesId・stage・おなか・けんこう・ごきげん・なつき・そだち・今日の ありがとう済み・今日の条件時間）、1日の回数カウンタ、ミッションの進みと受け取りずみ、図鑑（買ったことのある id）、チュートリアルのステップ。
- 保存のタイミング：お世話・買い物のたび ＋ ゲーム1時間ごと ＋ visibilitychange で hidden になったとき。

## 15. 実装係への注意

- 数値は balance.js / items.js から読む。この文書の数字をコードに直書きしない。
- けんこう の下限 10 は tick のいちばん最後で必ずかける。わるいこと の合計は −3 まで。
- 確率・よい時間・そだち は「ゲーム内の整数時刻をまたいだとき」にまとめる。
- 「1日の上限」は ゲーム時計 6:00 で 0 に戻す。閉じている間は時間が止まるので、現実の日付は使わない。
- 道具は1こ持てばずっと使える。max が 1 の器具の値段は、v0.1 では チュートリアル後に買う場面がほぼ無い（後の版で部屋・水槽を増やすときに使う）。
- 絵がまだ無い：food_sinking・coral のアイコン、海水3種の魚（どれも v0.1 では出さない）。
